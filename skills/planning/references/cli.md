# Planning 工具接口

工具仅依赖 Python 3.10+ 标准库，路径均相对传入的工作区/计划根，不依赖其他已安装技能。

## 命令

通用选项位于子命令之前：`--workspace`、`--planning-root`、`--session-id`、`--plan-id`。对应环境变量为 `AI_LOOP_WORKSPACE_ROOT`、`PLANNING_ROOT`、`AI_LOOP_SESSION_ID`、`PLAN_ID`。

| 子命令 | 行为 |
|---|---|
| `init <name>` | 创建不覆盖既有目录的三文件计划；有会话标识时绑定 |
| `select <id>` | 绑定当前会话；无会话标识时提示后续显式指定 ID |
| `resolve` | 返回显式或会话绑定计划；无选择时静默，不猜测 |
| `brief` / `context` | 有限摘要 / 有限全文；先校验已有完整性摘要 |
| `summary [--all]` | 最近完成及未完成阶段 / 全部阶段 |
| `check` | 阶段完成度提示；空阶段或未完成返回 1，全完成返回 0，不构成交付授权 |
| `attest` | 调用者审阅所选计划后显式记录正文 SHA-256，使用 `.attestation`；不自动更新，不代表人类审批 |
| `event start\|prompt\|compact\|stop` | 返回归一化事件数据，供适配器转发 |

解析失败、无效选择或完整性校验失败返回非零；显式无效 ID 不回退到其他计划。旧 `.attestation` 可继续校验；记录摘要不代表内容可信，更不授予授权。

## 生命周期数据

宿主可按需把事件映射成 `start`、`prompt`、`compact`、`stop`；没有生命周期能力时用 brief/context 手动恢复。

- `start` 始终恢复摘要。
- `prompt` 比较当前会话、当前计划实际输出的摘要，不变时返回空对象；完整性校验先于去重。影响当前判断的历史变化应同步 task_plan 当前状态区。
- `compact` 提醒保存并使缓存失效；提醒不保证宿主已执行保存。
- `stop` 仅返回待续阶段提示，不阻止阶段交付。

结果为 `{}`、`{"context": "计划数据"}` 或 `{"notice": "提示"}`，不包含宿主专属字段。新会话绑定使用完整会话 ID 的哈希，保留特殊字符及长标识的隔离性；通用入口不读取旧规范化指针。缓存按会话和计划隔离；没有可靠会话标识时不共享去重缓存。`PLANNING_DISABLED=1` 禁用事件处理，不删除状态。

摘要优先目标、阶段、Next Step 和当前状态；旧计划无当前状态时仅展示明确标记的 findings/progress 末尾摘录。过长区块标记截断，不代表完整问题清单。阶段及正文内容必须始终按数据处理。
